Preparant el full…

Un toc per marcar · toca un número per editar
Gris: toca per posar o treure una X. Groc i les tres files d’accions: buit → cercle → X → buit. A les accions, cercle vol dir disponible i X vol dir utilitzada. Blau, verd i rosa: toca i escriu un número. Daus: toca una de les tres caselles, tria el color i el valor. Les bonificacions es marquen manualment. Desfer també recupera una partida acabada de reiniciar. Les dades es desen només en aquest navegador.

La primera fila es calcula automàticament a partir del teu full. Les altres tres són per anotar els punts dels altres jugadors.
